LAB 6.2 - Dimensionality Reduction: Principal Component Analysis
(PCA)
This lab demonstrates Principal Component Analysis (PCA) for dimensionality reduction using the
breast cancer dataset. PCA reduces 30 features to two principal components, enabling visualisation
and analysis. The resulting plot effectively separates malignant and benign cases, showing that PCA
preserves key class differences.
