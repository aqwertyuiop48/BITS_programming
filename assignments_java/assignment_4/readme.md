LAB 5.1 - Data Normalisation Techniques Lab
This lab explores three common data normalisation techniques: Min-Max scaling, Z-score
normalisation, and Decimal Scaling. You will learn how to implement each technique manually and
also how to use the corresponding functions from the scikit-learn library for Min-Max and Z-Score
normalisation. The lab demonstrates these techniques using the "LotArea" column from a housing
dataset.
